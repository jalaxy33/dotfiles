# .cargo/config.toml  - config for rust nightly toolchain
#
# Please install nightly toolchain first:
# $ rustup toolchain install nightly
# 
# Put this at one of:
#     ~/.cargo/config.toml
#     <project-root>/.cargo/config.toml
# 
#   (For Windows: change ~ to `C:\Users\<user>` or `C:\Users\<user>\AppData\Roaming` )
# 
# Reference:
#     https://bevy.org/learn/quick-start/getting-started/setup/#enable-fast-compiles-optional 
#
